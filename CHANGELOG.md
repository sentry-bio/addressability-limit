# Changelog

This file records public changes to the manuscript and its machine-checked
companion. The repository history predating this file is not retrospectively
versioned.

## Unreleased

### Theory

- Recast the central object as a capacity profile relative to a basepoint,
  resolution, source family, structural obligation, and radial rate.
- Separated source, code, and obligation, and distinguished fixed-source
  representability from family-level achievability.
- Made retention a source property and base feasibility compulsory.
- Restricted distortion and motion parameters to their lawful ranges.
- Added the Structured Addressability Limit
  `β ≤ C_𝒜 ≤ C_block = c h_pack` under depthwise recoding.
- Made uniform local finiteness the canonical relational source class.
- Constructed asymptotic block exactness from independent optimal packings.
- Named homogeneous positivity and zero-tax as open claims, not theorems.
  Tessera–Cornulier and Kerr support positivity; Skenderi is the rank-one
  equality case.
- Restated the balloon against the ULF binary tree of Theorem 5.3's source
  class, and Lean-checked the geometric block-versus-relational gap.

### Formalization

- Added finite-radius measurable packing inequalities and exact finite block
  codes, plus constructive asymptotic block identity in the profile API.
- Added one-point-host regression theorems exposing vacuous capacity when base
  feasibility is omitted.
- Added the balloon host and a Lean-checked separation
  `balloon_separates`: the ULF binary tree is block-achievable and not
  relationally representable.
- Isolated curvature and state-equation statements behind an optional
  space-form chart.

### Documentation

- Distinguished defined, Lean-checked, paper-proved, and open claims.
- Added citation metadata and reproducible build instructions.
